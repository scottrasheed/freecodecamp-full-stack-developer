# Design a Set of Colored Boxes

A freeCodeCamp Responsive Web Design lab focused on practicing different CSS color formats by creating a set of colored boxes.

## Preview

A simple grid containing five colored boxes, with each box using a different CSS color format.

## Project Overview

This lab demonstrates how to apply different types of CSS color values to HTML elements.

The five boxes use:

* Hexadecimal color
* RGB color
* Predefined color name
* HSL color
* A standard CSS color value

## What I Learned

* How to use hexadecimal colors in CSS
* How to use `rgb()` colors
* How to use predefined CSS color names
* How to use `hsl()` colors
* How to apply background colors with CSS
* How to organize multiple elements using CSS classes
* How to link an external stylesheet to an HTML document

## How to View

1. Open the project folder in VS Code.
2. Open `index.html` with Live Server.
3. View the colored boxes in your browser.

## Expected Output

The page should display five visible colored boxes inside a `.color-grid` container. Each box should use the required CSS color format and the page background should be `#f4f4f4`.
