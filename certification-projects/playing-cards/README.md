# Playing Cards

## Preview

A responsive playing card layout built with HTML and CSS using Flexbox.

## Project Overview

This project is part of the **freeCodeCamp Responsive Web Design Certification**. It demonstrates how to create and organize playing cards using semantic HTML and CSS Flexbox.

The page displays three playing cards with different suits and values, arranged using a flexible layout that can wrap on smaller screens.

## What I Learned

* How to structure playing cards with HTML
* How to use CSS Flexbox for page layouts
* How to horizontally center and wrap flex items
* How to use `justify-content: space-between`
* How to use `align-self` to position individual flex items
* How to arrange content vertically with `flex-direction: column`
* How to use playing card Unicode symbols such as `♠`, `♥`, and `♦`

## Expected Output

The page displays three playing cards arranged horizontally with spacing between them. The cards can wrap onto additional rows when the available screen width is reduced.
